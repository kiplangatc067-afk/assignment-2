# My Personal Portfolio Website

This is my personal portfolio website created as a first-year ICT student at KCA University.

## Assignment 2 Features
- Projects page with 3 project cards
- Skills section with proficiency bars
- Services section
- JavaScript project filtering
- Expand/collapse project details
- Contact form with JavaScript validation
- Updated navigation between Home, Projects and Contact

## Built With
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in a browser, then select **Projects** from the navigation bar.
